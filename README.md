# Calculadora

Uma calculadora simples desenvolvida em Python como exercício de lógica de programação e prática com funções.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Menu interativo pelo terminal

## Tecnologias

- Python

## Como executar

É necessário ter o Python instalado.

No terminal, execute:

```bash
python calculadora.py
